Contour Vision

HackMIT 2026

Built for HackMIT 2026, Contour is a CPU-only tool for building and comparing computer-vision pipelines. It can measure simple objects and export the final pipeline as C++.

View source on GitHub

What It Does

  • Chains image-processing steps together and previews the result immediately.
  • Compares different transforms and pipelines without requiring a GPU.
  • Measures object length, width, area, orientation, center, and mean color, with calibration for physical dimensions.
  • Can suggest a pipeline with AI, but saves the suggestion as a normal graph that the user can inspect and change.
  • Exports C++ programs that do not require Python, an AI model, an API key, or a GPU at runtime.

Implementation

The frontend uses plain JavaScript and CSS. The FastAPI backend uses OpenCV, a small CImg bridge, and ZXing-C++ for image processing and barcode support. The preview and C++ export both use the same operation graph.

Validation

The project has 140 Python tests and 50 JavaScript tests covering 60 images and 159 processing branches. Three exported C++ pipelines were also tested on nine images and compared with the browser preview.
